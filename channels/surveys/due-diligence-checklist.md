# PSP 尽调清单

> 对接新支付渠道前的标准调研项。可复制到 Notion/飞书，按渠道逐项填写。

## 1. 基础信息

- [ ] 公司全称 & 注册地
- [ ] 持牌情况（MSB、EMI、支付牌照等）
- [ ] 服务地区与禁运名单
- [ ] 支持币种 & 结算币种
- [ ] 官网 & 技术文档链接

## 2. 费率与结算

- [ ] 交易费率（卡 / 本地方式 / 钱包 分项）
- [ ] 固定费用、货币转换费、拒付费
- [ ] 结算周期（T+N）& 最低结算额
- [ ] 滚动保证金比例与释放周期
- [ ] 是否有议价空间（量级门槛）

## 3. 能力与集成

- [ ] 支持的支付方式列表
- [ ] API / SDK / 跳转 / Hosted Page
- [ ] Webhook 事件完整性
- [ ] 沙箱环境质量
- [ ] 分账 / Marketplace / Connect 能力

## 4. 合规与风控

- [ ] KYB/KYC 要求与审核周期
- [ ] MCC 限制 & 禁售品类
- [ ] 3DS / SCA 支持
- [ ] 拒付率阈值 & 账户冻结政策
- [ ] PCI 责任划分

## 5. 运营与支持

- [ ] 客服响应 SLA
- [ ] 中文/本地语言支持
- [ ] 对账报表格式
- [ ] 历史稳定性（可查 status page）

## 评分建议

| 维度 | 权重 |
|------|------|
| 地区/币种覆盖 | 25% |
| 费率竞争力 | 20% |
| 集成复杂度 | 15% |
| 合规风险 | 20% |
| 本地方式丰富度 | 20% |
