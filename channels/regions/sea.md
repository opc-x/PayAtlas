# 东南亚（SEA）支付调研要点

## 市场特征

- 卡渗透率低于欧美，**电子钱包 + 银行转账** 是主流
- 各国本地方式差异大，单一全球 PSP 往往不够
- 监管碎片化：印尼 OJK、菲律宾 BSP、新加坡 MAS 等

## 常见本地方式

| 国家 | 主流方式 |
|------|----------|
| 印尼 | GoPay、OVO、DANA、VA 转账 |
| 菲律宾 | GCash、Maya、银行转账 |
| 泰国 | PromptPay、TrueMoney |
| 越南 | MoMo、银行转账 |
| 新加坡 | PayNow、GrabPay、卡 |

## 推荐调研路径

1. 全球 PSP 在 SEA 的覆盖深度（Stripe、Adyen）
2. 本地/区域 PSP（Xendit、2C2P、Airwallex）
3. 是否需要 **双通道**：全球卡 + 本地钱包

## 常见坑

- 结算币种与汇损
- 本地方式退款路径不一致
- KYB 需本地实体或代理
